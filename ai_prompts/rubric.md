# Evaluation Rubric For AI Outputs

Use this to score student or AI-generated answers.

## Create Model (0-10)

- Correct model grain (0-2)
- Correct dependency usage via `ref()` (0-2)
- SQL correctness and clarity (0-2)
- Includes tests/docs update (0-2)
- Naming/style follows project conventions (0-2)

## Explain Code (0-10)

- Correct business purpose (0-2)
- Correct lineage and inputs (0-2)
- Correct grain and transformations (0-2)
- Identifies real risks/edge cases (0-2)
- Clear, teachable language (0-2)

## Suggest Improvements (0-10)

- Prioritization quality (0-2)
- Practicality of recommendations (0-2)
- Correctness impact covered (0-2)
- Test/doc suggestions included (0-2)
- Concrete implementation snippets (0-2)
