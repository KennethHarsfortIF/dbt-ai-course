# Prompt 4: Ask AI to Help Extract the Right Data

These are facilitator examples and reference prompts.
Learners should write their own prompt using the exercise brief, not copy these by default.

## Example Prompt A: Lightweight Data Extraction Prompt

```text
Create a query that show Which orders had the highest revenue this month?

Task:
1) Identify the best model or table to use.
2) Suggest a simple SQL query .
3) Explain what the output would tell a business user.

Important:
- Describe the logic clearly.

Return exactly:
1) The model or table to use
2) The SQL transformation, stored in the playground model
3) A short explanation of the output
```
