# Answer Key 4: Ask AI to Help Extract the Right Data

Strong answers should:

1. Pick one clear business question instead of trying to cover the whole project
2. Identify the most relevant model or table to use
3. Suggest one practical extraction or shaping approach, even if it is only a rough SQL idea
4. Keep the scope narrow and focused on one question
5. Explain why the result would help a business user

Good beginner-friendly choices:

- Which customers are most active?
- Which subscriptions are likely to be renewed soon?
- Which orders had the highest revenue this month?

Common mistakes:

- Giving a vague question with no clear business focus
- Suggesting a broad query that mixes too many topics at once
- Requiring advanced dbt knowledge without explaining the idea simply
- Failing to explain what the output would help someone understand
