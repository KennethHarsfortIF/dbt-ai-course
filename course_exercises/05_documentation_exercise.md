# Exercise 5: Ask AI to Write Documentation

## Objective

Practice using AI to turn a model or dataset into clear, useful documentation that someone else can understand and trust.

## Your Starting Point

Choose one model in the project that you want to understand better. Good examples include `dim_customers`, `fct_orders`, or `rpt_saas_mrr`.

Before you write anything, think about what a new teammate or stakeholder would need to know about the model. What does it represent? What are the key fields? What assumptions or caveats should be documented?

Write a prompt that asks AI to help you create documentation for that model.

## Task

Write a prompt that asks AI to:

1. explain what the model is for in plain English
2. describe the most important columns or business logic
3. highlight any assumptions, limitations, or caveats
4. produce documentation that could be used in a README, schema description, or model notes

Keep the scope narrow. One model, one audience, one clear documentation goal.

## Submission Checklist

1. The prompt is specific and not generic
2. It focuses on one clear model
3. It asks for practical documentation, not just a summary
4. It includes a short explanation of why the documentation would help someone else
