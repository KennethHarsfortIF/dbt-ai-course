# Exercise 4: Ask AI to Help Extract the Right Data

## Objective

Practice using AI as a coding partner when you need to turn a business question into a practical data request.

## Your Starting Point

Think of a simple question someone might ask about the data. For example:

- Which customers are most active?
- Which subscriptions are likely to be renewed soon?
- Which orders had the highest revenue this month?

Use the models already in this project as your starting point.

## Task

Your prompt should ask AI to:

1. identify the most relevant model or tables to use
2. suggest a simple SQL query or data transformation approach
3. explain the output in a way a business user could understand

Keep the scope narrow. One question, one output, one clear direction.

## Submission Checklist

1. The prompt is specific and not generic
2. It focuses on one clear business question
3. It asks for a practical extraction
4. It includes a short explanation of what the output
