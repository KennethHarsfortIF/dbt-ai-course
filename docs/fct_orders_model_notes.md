# fct_orders model notes

This model is intended for analysts who need a practical, order-level view of business activity. It combines order-level fields with payment-level context to support basic reporting on order value, payment outcome, and successful order completion.

Use this model when you want to answer questions such as:

- How much revenue is tied to completed orders?
- Which orders were successfully paid?
- What payment methods were used for orders?

The model is intentionally simple and is designed for learning and exploratory analysis rather than for production-grade financial reconciliation.
